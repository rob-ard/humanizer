# Humanizer

Una skill per rivedere testi in modo naturale e specifico, mantenendo voce, significato, fatti, fonti e formattazione dell’autore.

## Contenuto

- `SKILL.md`: istruzioni della skill e criteri di revisione, inclusi i controlli specifici per Wikipedia.

## Installazione in Codex

Copia `SKILL.md` in una cartella chiamata `humanizer` dentro la directory delle skill di Codex:

```text
~/.codex/skills/humanizer/SKILL.md
```

Riavvia o aggiorna Codex se la skill non compare subito.

## Ambito

La skill migliora la scrittura, ma non promette di aggirare o superare i rilevatori di testo generato dall’IA.
